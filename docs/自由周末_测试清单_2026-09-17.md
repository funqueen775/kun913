## 一、两格周末（A 件）

| # | 测试点 | 怎么触发 | 预期 |
|---|---|---|---|
| 1.1 | 面板自动弹出 | 推进到第 3 / 6 / 9…月（每 3 个月，本月无待结算主线时） | 弹出「第 N 月 · 自由周末」，首屏是**两格空表**（周六上午/周六下午），不是旧的"选一件事" |
| 1.2 | 填格不结算 | 选区域→选活动，填进第 1 格 | **没有任何数值跳动**（以前选完就结算）；格子显示活动+同伴；右侧出现「清空」 |
| 1.3 | 同活动不可重复 | 第 1 格填了某活动，再进活动列表 | 该活动置灰、写「已经排进另一格了」，点不动 |
| 1.4 | 清空/改格 | 点已填格的「清空」再选别的 | 回到留白；重新填不报错 |
| 1.5 | 全留白也走得通 | 两格都不填，点「就这样过」 | 不拦人、不报错；手账两行都写「留白」 |
| 1.6 | 组合效果 | 两格都选技术类（加班/自习/博客）→ 结算 | 生命 −1，手账多一句「两天都没离开工位。这很像你——但身体记着账。」（其余组合：都给人 −1 / 都给自己 +1 / 一人一自 +1 / 同区两格主属性 +1） |
| 1.7 | 决策点只演一次 | 某格选湖边散步深谈/密室/篝火/年会排练之一，收束 | 只弹一屏决策；另一格不弹，手账里降级成一行 |

## 二、手账页（C 件）

| # | 测试点 | 预期 |
|---|---|---|
| 2.1 | 零数字红线 | 手账页**任何一行**都没有「好感 +N」「专业 +N」这类数字流水 |
| 2.2 | 格数人话 | 有一句「这段周末，你给了技术 2 格。」这类结构总结 |
| 2.3 | 关系人话 | 有同行者的活动 → 一句方向性描述（如「和王哥之间，从寒暄变成了能说点真的」），没有分数 |
| 2.4 | 手写一行 | 底部输入框写一句 → 收束后进记忆墙（心湖墙上多一张便签） |

## 三、在场一幕（B 件）

| # | 测试点 | 怎么触发 | 预期 |
|---|---|---|---|
| 3.1 | 撞见屏 | 填**食堂约饭 / 草坪打球 / 篝火烧烤 / 一起自习 / 桌游局**之一（5 个新加的），收束 | 插一屏「XX · 撞见」：一句场景（{谁} 已换成同行者名）+ 3 个应答按钮 |
| 3.2 | 应答不改数值 | 分别试三个应答，对照结算前后 | 生命/专业/产出**一个数都不变**；手账多「—— 在场一幕 ——」块 + 一行「记住了你：XXX」 |
| 3.3 | 一周末最多一屏 | 两格都选 3.1 里的活动 | 只演一屏，另一格只是手账里一行 |
| 3.4 | 优先级 | 一格有决策点（湖边深谈）+ 一格有撞见 | 决策点优先，撞见让位 |
| 3.5 | 无同伴不演 | 格子选独处类（湖边独走/图书馆） | 直接进手账，不弹撞见屏 |
