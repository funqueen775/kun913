熊心壮职 · 小镇自由活动与好感度系统设计 V1

配套：剧情册 V2（30 主线事件）、算法册 V1（行为编码）、五模块结合设计 V1（记忆墙映射）、美术方案 V2.2（等距场景）。

定位：P5 式日常层。主线 30 个剧情决策点之外，每 3 个月 1 个「自由周末」（共 16 个），玩家在熊心小镇里自主决定这段时间给谁、给什么。这是比剧情选择题更纯的偏好暴露——没有场景压力、没有对错，选什么全凭本能。

借鉴：华为小镇方法论（低密组团 / 小火车作为空间胶水 / 生活配套长在组团旁）+ P5 结构（主线 / 日常 / 好感度解锁）。

二、19 个活动详设（含 V5.4 新增工作型 W1-W5）

独处类（4 个）

S1 图书馆自习：S+1、H−1。文本：图书馆是园区里最安静的地方，牛津式的回廊把嘈杂全挡在外面。埋点：独处型信号。

S2 湖边独走：H+1；15% 概率触发「顿悟」flag（下次技术类事件 S+1，文案：「走着走着，那个卡了三天的问题突然就通了」）。练秋湖中心水岸概念。

S3 天台吹风：H+2。变体：若当前 H≤3，追加安慰文本「风把脑子里乱糟糟的东西吹散了一点。楼下有人喊你打球，你摆摆手——今天就想一个人待着」。

S4 工位加班：O+1、H−2。自由周末还选择加班，本身就是强 C（尽责）行为锚点（loading 0.50 × 弱情境）。文案：「整层楼只剩你一个人的屏幕亮着。你说不清这是上进还是不会休息——反正活是往前走了。」

双人类（5 + 1 彩蛋）

D1 食堂约饭：好感+3、N+1。约不同 NPC 话题不同（变体）：王哥聊技术圈八卦／小林吐槽客户／小赵问学习问题／老周讲当年。原型 CareerSim #31（38 次）。

D2 湖边散步深谈：好感+8、H+1。好感 ≥40（Lv3）首次触发「知心时刻」（见第四章），此后变为普通深谈（好感+5）。低频高收益，四种社交画像中「深谈型」的主信号。

D3 球场打球：好感+5、H+2。变体：约老周打球有特殊文本（他球风稳，输了也不恼：「打球和做事一样，急不得」）。原型 #65 午休羽毛球。

D4 夜宵烧烤：好感+6、H−1。30% 概率触发对方掏心窝（提前 10 分解锁知心时刻的内容，但好感收益少 2——想早听秘密，就得接受这段关系「来得快但欠火候」）。

D5 一起自习：好感+4、S+1。安静型社交。约小赵有专属文本（他学习很认真，你教他一个知识点，他记在手机备忘录里，备注是「X 月 X 日，X 哥/姐教的」）。

D6 雨天共伞（彩蛋）：好感+6、特殊灰金便签「那把伞」。触发条件：自由周末为雨天（20%）+ 离开时与某 NPC 同出口（随机）。自动剧情无决策。原型 #35「暴雨下班仅有一伞与小赵」。

团建类（4 个）

G1 密室逃脱（3 人）：好感+5×2、H−1。带决策点（见第三章）。原型 #102「密室逃脱领导拖后腿同事惊艳」——随机一名队友卡关（拖后腿者 40% 是老周/熊总，40% 小赵，20% 小林——领导拖后腿的经典局面）。

G2 KTV（2-3 人）：好感+4、H−1。带决策点：30% 概率熊总也在场（他点歌怀旧金曲），唱完把麦递给你。原型 #27「聚餐第二场 KTV 与晋升决策者」——D 维度的休闲娱乐测试。

G3 桌游局（3 人）：好感+4、S+1。变体：小赵玩桌游意外地强（反差萌文本：「平时说话都不大声的人，赢了三局」）。

G4 年会节目排练（团队）：好感+3×参与 NPC。带决策点：报名时选上台角色还是幕后。E（外向性）行为锚点主测量点之一。原型 #11「年会被起哄上台表演」+ #24「年会节目排练占用时间」。

G1 密室逃脱 · 队友卡关

情境：最后一关，倒计时 5 分钟。小赵盯着谜题满头汗，一眼就能看出他卡住了。

选项 效果 marker 文本反馈
A 上前一起解 好感+2（小赵）、S+1 E+（0.43×弱情境） 「你们头碰着头试了三种可能，门开的那一刻，小赵喊得比谁都大声」
B 给提示不代劳 好感+3（小赵）、A+ A+（0.52） 「你只说了一句『看看墙角』。小赵愣了两秒，回头看你，眼睛亮了」
C 站着等 无 E−（0.43） 「你靠在墙边看完了全程。出去后没人说什么，但也没人提刚才」

G2 KTV · 熊总递麦

情境：熊总唱完一首老歌，把麦往你这边递：「来一个？」

选项 效果 marker
A 接了唱 好感+3（熊总）、E+、D 小加成 熊总记忆标签「放得开」
B 推给旁边的同事 好感+1 社交策略数据
C 借口去洗手间 好感−1、E− 熊总记忆标签「放不开」

D2 散步深谈 · 知心时刻的回应

情境：对方讲完私人故事，反问你。

选项 效果

B 只倾听 好感+2、「倾听者」便签

B 报幕后 好感+1、H+1 E−

四、好感度系统

数值与等级（对玩家隐藏，红线）

NPCRelation：user_id + npc_id + score(0-100) + level(1-5) + flags
阈值：Lv1 0-19 / Lv2 20-39 / Lv3 40-59 / Lv4 60-79 / Lv5 80+
视觉表达：记忆墙该 NPC 便签颜色渐进（蓝→黄→金，美术五模块设计已定）

每级解锁

级 解锁 说明
Lv1 初识 正常对话 —
Lv2 熟人 知心时刻（私人故事支线） Lv2 后首次 D2/D4 深谈触发，每 NPC 一次性
Lv3 伙伴 剧情事件专属选项 T5「王哥背书」、P5 事故小赵主动分担——已有伏笔正式挂到好感条件
Lv4 挚友 关键事件主动出现 考核窗前提醒你、事故时第一个站出来
Lv5 知己 第 48 月专属告别台词 + 人格卡徽章 终局彩蛋

四段「知心时刻」剧情文本（Lv2 核心内容）

王哥（技术路线的私事）： 「三年前我也坐过那个答辩席。」他摘下眼镜擦了擦。「那天我讲的是管理成果，掌声很响。可台下鼓掌的人，没有一个记得我写过什么代码。第二周我申请转回技术，薪级降了一档，所有人都说我傻。」他把眼镜戴回去，「所以上次你问我走技术还是管理，我没资格替你选。我只知道，技术这碗饭，我吃得踏实。」

小林（甩锅背后的东西）： 「这个月我的需求被砍了三个。」他笑得有点勉强。「你们背后肯定说我甩锅……随便吧。每次复盘会我手心都在出汗——需求被砍的那一刻，我在老板眼里就是个『提错需求的人』。我不敢认，因为认了，下次连站上会议桌的资格都没有。」他顿了顿，「你今天肯坐在这听我说这个，我记着。」

小赵（不敢发言的过去）： 「大一那年我在班上发言，讲到一半忘词了。」他搅着咖啡，没抬头。「全班笑了半分钟。从那以后我开会只敢坐最后一排。」咖啡凉了他也没喝。「上个月你非说『小赵你来讲』——我腿一直在抖。但你不知道，那是我三年来第一次主动站起来。」

老周（P3 侵占署名的动机伏笔）： 「我入职第二年做的模块拿了公司金奖。」他喝了口茶。「领奖台上站着的，是我组长。」茶杯放下的声音很轻。「我没闹。我记了十年——不是为了记仇，是怕自己变成那样的人。」他看了你一眼。「结果前阵子，差点就变了。小赵那事，谢谢你。」

设计意图：四段故事让每个 NPC 立体化——职场里每个让你不舒服的人，都有他自己的困境。这是 P5「每个 Confidant 都有自己的战役」的本土化，也让 P3 侵占署名、M5 路线选择、N2 被轻视这些主线事件在情感上闭环。

五、系统规则汇总（后端）

  1. 调度：每 3 个月一个自由周末（第 3/6/9…48 月），共 16 个；主线事件月的自由周末照常（自由活动与主线不互斥，只是当月多一个时段）。
  2. 天气：80% 晴 / 20% 雨；雨天开放 D6 共伞彩蛋。
  3. 收益递减：same_npc_3x_half。
  4. 知心时刻一次性：触发后 D2/D4 降为普通深谈（+5）。
  5. 数值隐藏：好感度、等级、解锁条件一律不下发前端。
  6. 预标定：所有活动的六维增减与决策点 marker 均预标定，走现有 EventConfig 体系，不引入未标定内容。

七、测量兼容（为什么这个系统让测评更准）

  1. 更纯的偏好暴露：无场景压力、无对错，把周末给谁是本能选择；
  2. 社交指纹 2.0：三维轨迹（去哪组团 × 和谁 × 活动类型），输出四种社交画像——独处型 / 深谈型 / 玩乐型 / 聚会型；
  3. BARS 兼容：选密室=抗压与协作锚点、选上台=E 锚点、自由周末加班=强 C 锚点——活动选择本身进入行为编码；
  4. 好感度 vs 六维交叉：某 NPC 好感很高但你剧情里对他选过负面选项 → 矛盾素材（「你嘴上嫌他，周末却总往他那跑」）。

八、后端落地清单（给你）

  1. 建 NPCRelation 表 + 好感度结算接口（活动完成 → 加减分 → 判级 → 下发记忆墙更新事件）；
  2. explore_click 埋点扩展字段；
  3. 16 个自由周末的调度钩子（挂进月度推进循环）；
  4. 天气随机数与 D6 触发逻辑；
  5. 收益递减与知心时刻一次性标记；
  6. Lv3 解锁选项：主线事件 JSON 的 conditional_modifiers 增加 affinity_lte/gte 条件类型（需在结算器支持）；
  7. Lv4 主动出现：事件调度器加「挚友干涉」触发类型；
  8. Lv5 终局告别：报告生成器读好感等级选告别文本。
