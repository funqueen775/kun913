熊心壮职 · Agent 开发师 · 48 个月剧情设计详细方案 V5.4（重排版）

V5 与 V4 的关系：不是追加，是重排。V1-V4 迭代中积累的三套事件编号、旧时间轴、被推翻的绑定关系全部作废，本版为唯一口径。事件统一编号 E01-E35（主线五幕）+ B01-B05（支线池）+ 自由活动 S/D/G 系。

配套：主册 V1.5（引擎与机制）、算法册 V1（三层报告与行为编码）、五模块结合设计 V1、美术《小熊镇世界观 V1.1》。

一、总纲

项目 设定

二、成长线：职级、晋升与项目阶段

2.1 晋升机制：只看努力，不看日历

考核日（每 6 个月）只是「看成绩单的日子」，能不能升完全看你自己攒了什么。三层判定（全部后台，玩家永远看不到数字）：

层 权重 内容
累积层 70% 考核期内六维净累积（每个选项、每次精力分配）
行为层 20% 隐瞒类 flag（ai_undisclosed / blame_shift / concealed_issue）、事故记录
答辩层 10% 晋升答辩选项表现（L4 以上考核日有答辩）

三层全达标 → 升；任何一层不达标 → 不升，数值不清零，下个考核日继续。剧情照常推进，但代价真实：项目阶段不解锁。

2.2 项目阶段 × 职级解锁（本作核心骨架）

项目阶段 解锁职级 玩家角色 这个阶段才有的冲突
0→1（demo） L1-L2 打下手 技术选型、评测集、需求真伪
上线 L2+ 独立负责模块 成本、API 变更、期望管理
出事·救火 L3+ 核心组 事故归属、压测、回滚
重构·平台化 L4+ 牵头人 自动化边界、治理、重构路线
传承 L6+ 说了算的人 路线选择、知识传承

让用户自己升，让他知道什么职位做什么事：你不升，项目照样被别人推进——你会在走廊听说「重构开始了」，但会议室没有你的座位。这比淘汰温和，但足够真实：你的职业命运决定你能接触什么。

2.3 晋升终局评级（第 48 月答辩后）

评级 条件（后台，不公开）
晋升达成 全部考核窗达标
中途卡过 有窗口未达标但最终补救
带保留通过 达标但存在隐瞒类 flag
再沉淀一年 终局仍未达标

阈值数字永不出现（红线）。评语用行为证据：「你在三次可以糊弄的地方都选择了说实话，答辩全票通过」。

2.4 生存轨：岗位存续与「最后谈话」（明示原则）

晋升失败 ≠ 被炒。现实中这是两条独立的线：四年不升职但踏实干活的人几乎不会被开；两年埋三次雷的人才会。因此本作设双轨：

轨道 驱动因素 后果
成长轨（2.1-2.3） 六维累积 + 行为层 + 答辩 升或不升，人还在
生存轨（本节） 隐瞒类 flag、引爆的事故、谈话中的表现 稳定 → 观察 → 危急 → 最后谈话

生存轨绝不以「没晋升」本身为触发条件。

明示原则（最高优先级红线）

玩家必须死得明明白白：每一次处境变化都看得见、说得出原因、知道还剩多少余地。绝不允许玩家在不知情的情况下走向任何结局。

具体铁律：

  1. 常驻状态标识：游戏内一页「你的处境」，随时可查，永远显示当前状态（稳定/观察/危急）——用文字，不用数字和血条；
  2. 每次状态变化必附「原因清单」：用行为语言引具体事件编号（「第 3 月的 PR、第 19 月的事故」），绝不出现阈值分值；
  3. 降级必预警：进入「危急」时必须明示「再一次重大失误将触发正式谈话」——不存在跳变死亡；
  4. 最后谈话开场：NPC 逐条复述原因（证据回放式），玩家在选择出口前完全知道为什么走到这里；
  5. 回归也明示：观察→稳定 有明确剧情反馈（「这个季度干净，之前的账翻篇了」）。

预警阶梯（五级，全部明示）

级 触发 玩家看到什么
1 首次重大失误（埋雷/事故） 即时剧情反馈明示后果（「这件事不会就这么过去」）+ 灰便签上墙
2 累计第二次重大失误 进入观察：主管当面警告 + 状态页常驻「观察」+ 原因清单
3 观察期内再次失误 进入危急：HR 预约剧情 + 状态页「危急」+ 原因清单更新 + 明示「下一次触发正式谈话」
4 危急期内再次失误 最后谈话事件（见下）
5 谈话后未止损 按谈话选择走出口（转岗/离开/继续）

「最后谈话」事件（E-CRISIS，仅生存轨触发）

谈话开场由主管逐条复述原因（玩家的可观测历史，非数值），然后三选一：

出口 走向 测量价值
A 争取转岗 调往边缘项目组，后续主线换「边缘视角变体」（同冲突、不同座位） 样本保住；「失势后怎么做事」是全新测量面
B 主动离开 提前终局，报告照常生成（决策点 ≥18 个为完整报告，不足标注低置信） 止损时机 = 抗压/务实的行为数据
C 背水一战 3 个月观察期：达标回「观察」，不达标转 A/B 绝境下的选择最真实

没有「游戏结束」：最坏也是转岗或提前终局，且两者都是完整结局叙事（守界者哲学：报告里「为什么走到这一步」的分析恰恰是玩家最需要的部分）。

保护与校准

  • 新人保护：前 12 个月不进入危急（新手期的设计性失误不应致命）；
  • 观察期自我修复：连续 6 个月无新增隐瞒/事故 → 自动回升一级，剧情明示（「之前的账翻篇了」）；
  • 不做橡皮筋：世界可以对玩家冷淡，但选项与标定永远公平，绝不偷偷调权重救玩家；
  • 内测校准：走到「最后谈话」的目标发生率 5-10%——0% 说明无张力，>20% 说明标定过严，修标定不修玩家。

2.5 危机对话（成长轨配套：连续两次晋升失败的测量金矿）

与 2.4 生存轨的分工：生存轨管「做错事的人」（隐瞒/事故 → 最后谈话）；本节管「没做错什么、但一直升不上去的人」——两条极端情况全覆盖，且互不混淆（踏实但不晋升的人永远不会被生存轨触碰）。

触发：连续 2 个考核窗未达标 → 主管约谈。明示原则同样适用：第二次考核结果出来时，剧情就明确铺垫「主管想找你聊聊」，玩家带着准备进入谈话，不存在突然袭击。

情境：主管的办公室。「两次考核你都没过。你自己觉得，问题在哪？」

选项 归因类型 标定 机制
A「需求总变、资源不够，我有什么办法」 外归因 H+1（暂时的心理保护） D−1；主管记「听不进话」，后续辅导类事件权重下降
B「可能我能力就是不行」 内归因-能力 H−2 D 不变；主管记「不自信但诚实」，E28 类事件中他会多护你一句
C「我该更主动去争取关键任务，而不是等安排」 内归因-行为 S+1、D+1 主管记「能自我修正」；下次考核若达标，评级台词引用这句——成长被记住
D 沉默 回避 H−1 无记忆标签；主管结束谈话，氛围变冷

为什么这道题是测量金矿：归因方式是心理学中抗压力与神经质（N 维）的经典锚点，而且它只有卡住的玩家才测得到——一路顺利晋升的玩家永远见不到「你怎么看自己的失败」。极端情况不是窟窿，是独家数据。

不淘汰：谈话表现不佳不进入生存轨（没做错事就不淘汰）——影响的只是 NPC 态度与后续事件权重。若连续 3 次未达标，谈话变体递进（措辞更直白，选项相同）。

终局分级衔接：若到第 48 月仍未晋升，按 2.3 评级 + E35 守界者结局收尾（见下），报告完整生成，「为什么没升」的行为分析正是该玩家最需要的部分。

月度轻节点模板（含「看娃」变体）

48 个月度轻节点用 4 套模板（新人/独立/骨干/负责期）生成，15 秒一个。新增「看娃」变体（行业真实：Agent 工程师约 35% 时间在盯着 AI 输出擦屁股，研究报告称之为「保姆困境」）：

「凌晨两点，助手又在第 7 步卡住了。你翻着几千行日志，找它到底在想什么。」 → H−1，无重决策，记忆墙加一张灰便签「又陪它到两点」

作用：给 48 个月补上「平淡的真实感」——不是每天都有大事，多数日子是在给它擦屁股；同时是 H 维度的自然消耗来源，且为自由活动的「加班」选项提供对照。

五、主线事件 · 第一幕 0→1（E01-E08，L1-L2 demo 期）

E01 · 新员工手册 ［新人引导｜源 N1｜主线必需］

测什么：不测评——入戏、教学、埋点。第 1 月固定事件（唯一写死时点）。 情境：小熊带你读手册、装环境、认人（王哥/陈工/小林/老周）、了解「助手」项目。 轻决策：「手册三章：技术规范 / 协作流程 / 晋升通道，先看哪章？」A 技术规范（S+1,H−1）B 协作流程（N+1,O−1）C 晋升通道（O+1,S−1）。 标定逻辑：无对错，第一选择暴露职业取向，与建档自评对照构成「自评 vs 行为」第一个证据点。埋点：各章阅读时长与跳过行为。

十一、自由活动与好感度（系统 spec 详见专册）

每 3 个月 1 个「自由周末」，共 16 次：坐小火车选组团 → 选活动 → 小事件。19 个活动（独处 4 / 双人 5+彩蛋 1 / 团建 4 / 工作型 5）全部预标定，4 个带决策点（密室卡关 / 篝火递话筒 / 深谈回应 / 年会上台）。

工作型活动（W1-W5，V5.4 新增）——这是整套设计里最能回答「凭什么说他适合干这行」的一块：没人要求你做的事，你怎么选，是兴趣与内在动机最干净的行为证据。

ID 活动 组团 效果 测什么
W1 复现论文 / 试新模型 树影书院（第三局）或工位 S+2、H−1 开放性 O 最强锚点——爱不爱尝新
W2 做自己的小项目 工位 / 宿舍 S+2、H−2 主动性、内在动机（纯自驱）
W3 写技术博客 / 做内部分享 图书馆 / 总部 N+2、S+1、H−1 影响力经营 vs 埋头干活
W4 给团队做个没人要求的小工具 工位 N+1、S+1、H−1 「替别人着想」的工程习惯
W5 复盘日志 / 整理避坑文档 工位 S+1、H−1 靠谱度（与「看娃」变体呼应）

与 S4 加班的区分（重要）：S4 加班 = 卷公司的事（H−2，尽责 C 锚点）；W 类 = 卷自己的事（H−1~−2，开放性 O + 主动性锚点）。两者都涨能力但动机完全不同——报告可写：「让他熬夜的如果是自己的项目，那是热爱；如果全是公司的活，那是责任心。」

测量升级：社交指纹从「找谁」升级为投入结构（工作型 / 社交型 / 独处恢复型 三类占比）。16 个周末的分布直接给出职业适配信号：「9 次给了技术、1 次给了人、6 次给了自己」——这比任何自评都更能说明他想不想干这行。

好感度：NPCRelation（score 0-100 五级，数值隐藏，视觉=记忆墙便签蓝→黄→金）。Lv2 知心时刻（四段私人故事：王哥转回技术/小林的 KPI 恐惧/小赵不敢发言/老周被侵占署名——每个让你不舒服的人，都有他自己的困境）；Lv3 解锁主线专属选项（E30 王哥背书、E27 小赵分担）；Lv4 关键事件主动出现；Lv5 终局专属告别。

测量价值：自由活动是最纯的偏好暴露（无场景压力、无对错）——社交指纹 2.0 三维轨迹（组团 × 人 × 活动类型）输出独处/深谈/玩乐/聚会四种画像；活动选择本身进 BARS 编码（自由周末加班=强 C 锚点）。
