熊心壮职 · 事件场景与人物对照表 V1

给谁看：美术（场景、道具、角色状态、场景残留）+ 前端（镜头切换、UI 特殊界面、微互动点）+ 策划（对表核对）。 依据：剧情册 V5.4（事件与标定）、美术《小熊镇世界观与场景设计说明 V1.1》（八组团与空间线）。 本表只定“这场戏怎么落地”，不改任何剧情数值。

一、通用规则（美术与前端必读）

1.1 四条通用规则

  1. 角色按事件流动，不按楼栋驻守：同一地点可以有不同组合，避免地图变成“部门标签墙”。
  2. 每场戏结束后，场景里必须留下点什么（美术 V1.1 的要求）：贴图、灯光、摆件、NPC 状态之一发生变化，让“你做过什么”在空间里可见。
  3. 镜头语言：跨组团走小火车转场（1.5 秒，有仪式感）；同组团内换位置直接切镜（0.3 秒）。
  4. 不透明机制的表达：隐藏风险不显示为血条——每次埋雷，心湖熊石雕塑区的「上锁抽屉」震动一声（音效+1 帧位移），玩家看得见“多了一样东西”但打不开。

九、给前端的交互清单

  1. 镜头调度：跨组团 = 小火车转场（1.5s）；同组团 = 直切（0.3s）；事故类 = 快速推近。
  2. 特殊 UI 界面（非对话框，需单独做）：PR 提交界面、成本账单弹窗、日志滚动界面、群聊界面、绩效打分滑动条、问卷界面。
  3. 微互动点三态：未触发（灰）/ 可点击（呼吸光）/ 已完成（置灰+勾选）——美术 V1.1 已定义。
  4. 上锁抽屉：埋雷时震动 + 音效，永不显示数量；第 22 月后若引爆则弹开（露出灰便签）。
  5. 状态页：「你的处境」（稳定/观察/危急）常驻入口，文字不用数字。
  6. 记忆墙：可随时打开，便签按 NPC 蓝→黄→金渐进；负面记忆用灰便签/倒贴。
