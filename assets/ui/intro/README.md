## 五位同事的头像：优先走纸娃娃图集

角色形象已定（2026-09-13）：**是熊**。

- **推荐做法**：美术出「熊的纸娃娃图集」，规格与 `assets/characters/paper_doll_64/` 一致
  （256×320、每帧 64×80、4 行=方向、4 列=动作、每帧 200ms，文件名 `compiled/<编号>_walk_64.png`）。
  开场头像会自动裁第 1 行第 1 列（朝下站立帧）当头像 —— **不用另外出 5 张头像 PNG**。
  只要文件名和 `data/story/intro.json` 里的 `paperDoll.atlasPattern` 规则一致，就不用改代码。
- 备选做法：美术单独出 5 张头像 PNG（`cast_wange.png` / `cast_chengong.png` / `cast_xiaolin.png` /
  `cast_laozhou.png` / `cast_xiaozhao.png`，256×256 透明底）。这条路需要改 `IntroSequence.gd`
  的头像分支，改之前先说一声。

当前画面里显示的头像，是从 `assets/characters/paper_doll_64/` 的**人类纸娃娃**图集裁出来的**临时占位**。
